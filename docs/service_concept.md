# サービスコンセプトとターゲット層の定義

本ドキュメントは、シニア層向けYouTube動画投稿代行サービス「Poco a Poco」の事業コンセプト、ターゲットユーザー、サービス仕様を定義したものです。

## 1. サービス概要

- サービス名: Poco a Poco（ポコアポコ）〜シニアのための家族向けYouTube投稿代行〜
- コンセプト: 「離れて暮らす子どもや孫へ、少しずつ、日々の暮らしと元気を届ける」
- 概要: 
  シニア夫婦が日常で撮影した動画（旅行、ガーデニング、ペット、日々の料理、孫へのメッセージなど）をLINEで送るだけで、余分な部分のカット、字幕入れ、エフェクト加工などを行い、YouTubeに代理でアップロード（家族限定公開または一般公開）するサービス。

## 2. ターゲット層（ペルソナ）

- メイン対象: 60代〜70代の定年退職した夫婦
- 特徴:
  - 子どもや孫が離れて暮らしており、もっと頻繁に交流したい。
  - スマートフォンは持っており、LINEで写真や短い動画を送ることはできる。
  - しかし、長尺の動画を送る方法や、YouTubeのチャンネル開設、動画のアップロード方法はわからない。
  - 普段の旅行や趣味（園芸、散歩、料理）の様子、元気な日々の姿を家族に残したい・伝えたいと思っている。
- ユーザーの動機:
  - 「孫に成長の様子を見せたい、自分たちの元気な様子も見せたい」
  - 「ビデオ通話もいいけれど、お互いの時間を合わせるのが大変。YouTubeなら好きな時にテレビやスマホで見てもらえる」

## 3. サービスの特徴と提供価値

- LINE特化の簡単送信: 
  やり取りはLINE公式アカウントに動画を送信するだけで完了する仕組み。お電話は使用しません。
- 送信容量に配慮した2つの動画スタイル:
  - スマートフォンから手軽に送れる「ショート動画（1分以内）」
  - 旅先やイベントの様子をじっくり見せる「ロング動画（10分以内）」
- 限定公開・一般公開が選べる安心設計:
  家族だけが視聴できる限定公開を基本としつつ、ご要望に応じて全体に公開する一般公開も選択可能です。
- 見やすく楽しい動画編集:
  不要な沈黙のカット、字幕（テロップ）の追加、楽しい音楽や効果音（エフェクト）の追加を行い、家族がテレビ等で楽しく見られるクオリティに仕上げます。
- 「チャンネル初期開設」の分かりやすい説明:
  「お客様専用のYouTube上の動画置き場（チャンネル）をセットアップする作業」であることを明記。初回登録時に無料で私たちが代行します。

## 4. 料金プラン

動画の長さや送信の手軽さに合わせて、2つの体系をご用意します。トラブル防止のため、各プランの動画の最大長を明確に定義しています。
